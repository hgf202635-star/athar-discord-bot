# أثر | بوت Discord الإسلامي

النسخة الأولية من بوت أثر. هذه النسخة تتضمن تسجيل الدخول إلى Discord وأمرين تجريبيين، وهي أساس نبني عليه النشر التلقائي والصور ولوحة التحكم.

## المتطلبات
- Node.js 20 أو أحدث
- تطبيق وبوت منشأ من Discord Developer Portal

## التشغيل على جهازك
1. نزّل المستودع.
2. نفّذ: `npm install`
3. انسخ `.env.example` إلى ملف باسم `.env`.
4. ضع توكن البوت في `DISCORD_TOKEN` ومعرف التطبيق في `CLIENT_ID`.
5. اختيارياً ضع معرف سيرفر الاختبار في `GUILD_ID`.
6. سجّل أوامر السلاش: `npm run deploy:commands`
7. شغّل البوت: `npm start`

## الأوامر الحالية
- `/ping` اختبار الاتصال.
- `/athar-help` معلومات المساعدة.

## الأمان
- لا ترفع ملف `.env` إلى GitHub.
- لا تضع Bot Token أو Client Secret داخل ملفات المشروع.
- إذا انكشف التوكن، أعد تعيينه فوراً من Discord Developer Portal.

## ما لم يُنفذ بعد
نظام اختيار القنوات، جدولة المنشورات، مصادر النصوص الشرعية الموثوقة، إنشاء بطاقات الصور، قاعدة بيانات مستقلة لكل سيرفر، وربط لوحة تحكم أثر بتسجيل دخول Discord OAuth2.
